Download field guide CSV
  1. Unzip and edit. The manifest records your selected fields and division mode. Edit the CSVs in a spreadsheet and save as UTF-8 CSV. Keep all headers; optional fighter cells may be blank.
  2. Keep related rows connected. Fighters use stable IDs inside the pack. Company assignments, opponents and championship holders refer to those IDs. History may be partial, but its W-L-D counts cannot exceed the stated record.
  3. ZIP and review. Keep the manifest and CSVs together at the ZIP root or in one folder. Import the ZIP in the new-world setup, review its counts and errors, then start the career. Invalid packs cannot create a save.

Starting worlds, not save replacements. Advanced imports are available only when creating a new single-player world. Existing careers can use Roster → Advanced world export to make a reusable starting-world pack. Use full save export for backups.

Company starting settings use the existing promotion IDs in the lookup list; this format does not create new company IDs or rename CPU promotions. Local promotion IDs support fighter placement. Prior history stays before the new career and does not generate organization records, revenue, or achievement credit. CPU interim titles are not supported. Advanced skill fields accept precise decimals from 0.5–5; simple CSV skills use half-point steps and export rounds more precise skill values to the nearest half point.

Choose whether to replace represented rosters, CPU company selection, or represented companies’ generated audiences. Otherwise the pack adds fighters and settings to the normal generated world. The three-fighter example is a format demonstration; add fighters before expecting a balanced playable world.

From spreadsheet to fight card

  1. Choose the matching roster. Open a single-player career with four or eight divisions. Download the matching sample, or start from the template.
  2. Edit and import. Save your spreadsheet as UTF-8 CSV. In the game, open Roster → Import fighters CSV, select the file, review the counts and any errors, then choose Apply import.
  3. Sign and book. Find the new fighters in the free-agent list and sign them. Both opponents must be eligible for the bout’s division.

Back up first. Export your full save before a bulk edit. CSV contains fighter details, not the complete world, contracts, events, or fight history.

Updating and sharing rosters

Edit your existing world

Use Export world fighters CSV to export active player, rival, local-promotion, and free-agent fighters. Keep IDs to update them. Existing contracts, memberships, identity traits, organization results, and historical fights stay attached to those fighters. Omitted rows do not delete anyone.

Changing an existing fighter’s division requires clearing bookings and draft selections, competition reservations, active division agreements, and held titles first.

Share a reusable roster

Clear the IDs before sharing with a different world. Blank IDs create new free agents with new identities and a 0-0-0 organization record. The CSV does not set personalities, styles, popularity, contracts, titles, or promotion memberships.

Import each blank-ID file once. Importing it again adds another copy. Export the world afterward and keep the generated IDs for future updates.

If the file won’t import

  • Use UTF-8 CSV, not an Excel workbook. Keep every header and do not add unsupported columns.
  • Keep the file at 5 MB or less, with 1–10,000 fighter rows. Use a decimal point for half-point skills, such as 3.5.
  • Check division mode, duplicate or unknown IDs, W-L-D formatting, and skill ranges.
  • Fix every reported error before applying. A file with validation errors makes no changes.

CSV import is available in ordinary and Sandbox single-player careers. It keeps your current game mode and rules. Online careers cannot import fighters. Direct profile editing remains a Sandbox feature.
