Project Romémon

An all-in-one Pokémon Platinum game creation toolkit. Nick is building tools that let players redesign the original Nintendo DS game or create their own customized Pokémon adventure without programming experience.

Satchmoe Studios and Project Romémon are not affiliated with, endorsed by, or sponsored by Nintendo, The Pokémon Company, or the Pokémon franchise in any way.

One application. More creative freedom.

A toolkit for your own Pokémon experience

Instead of switching between separate tools for individual parts of Pokémon Platinum, Project Romémon aims to bring editing into one comprehensive application. Nick's focus is making ROM editing intuitive and reliable for newcomers while giving experienced creators more freedom.

Planned features

These capabilities are planned or in development. They describe the project's direction, rather than a finished release.

Pokémon editing

Change Pokémon stats, moves, abilities, and other characteristics.

Trainer editing

Customize the trainers players encounter throughout the game.

World editing

Modify the game's existing maps, environments, and overworld.

Procedural world generation

Generate new maps automatically as starting points for your own creations. This planned feature is a central part of Nick's vision for the toolkit.

Built-in modifications

Toggle popular gameplay changes and features without manually programming them.

An approachable interface

Make complicated ROM editing accessible to people without coding experience.
